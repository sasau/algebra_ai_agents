TOPRIGHT public void interrupt();
Requests cooperative cancellation of TARGET thread. Does not force termination.
If target is blocked in sleep/join/wait, it may throw InterruptedException with
status cleared; arbitrary code must cooperate. Put detail in surrounding prose
if space tight. Diagram arrow is request to worker, not forced stopped marker.
BOTTOMLEFT public final boolean isAlive();
true means started AND not yet terminated. false also applies BEFORE start, so
false alone does not mean successful work. Read current state; no waiting.
BOTTOMRIGHT public boolean isInterrupted();
Reads target thread's interrupt status WITHOUT clearing it. Worker can check
Thread.currentThread().isInterrupted() during finite work units.
