# Actual evidence

`baseline/` contains fresh checks of this prepared JDK-backed starter.
These are preparation evidence, not accepted Java 04 implementation steps
and not proof that unattended native orchestration was tested.

During planning, save any new baseline runs in a new attempt directory.
Execution must obtain its own baseline evidence in its independent copy.
Each implementation step later records `step-NN/attempt-N/verification.md`,
command metadata, raw `.stdout.txt`/`.stderr.txt` and tested-file hashes.
Keep failed attempts. Follow workflow/checkpoints.md.
