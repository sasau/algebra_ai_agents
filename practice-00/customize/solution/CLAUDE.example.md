# practice-00 — Intro to LLMs lab

Two tracks, one lab: `ts/` (TypeScript) and `java/` (Java) run the same exercises.

## Commands
- Setup check: `cd ts && npm run check` · `cd java && ./gradlew checkSetup`
- Repo state (branch, changes, recent commits): run `./tools/git-summary.sh` — never guess.

## Rules
- Cite the exact file path when you mention code.
- Model ids live only in `ts/src/client.ts` and `java/src/main/java/lab/Client.java`.
- Never read, print or edit `.env`.
